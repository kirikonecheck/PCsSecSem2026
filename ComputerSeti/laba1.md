# Лабораторная работа №1 «Подключение персональногокомпьютера к локальной вычислительной сети»

## Цель работы: приобретение практических знаний и навыков в выборе и установке сетевых адаптеров, монтажу и разделке сетевого кабеля, физическому присоединению ЭВМ к кабельной системе при создании локальной компьютерной сети по технологии Ethernet.

## Материалы, оборудование, программное обеспечение: IBM PC-совместимый персональный компьютер, сетевая карта (для шины данных PCI) производительностью 10-100 Mbit/сек с разъемом RJ-45, кабель UTP категории 5, вилки RJ-45, обжимной инструмент. Критерии положительной оценки: выполнение типового задания, оформление отчета по работе, ответы на вопросы для самопроверки.

## Ход работы

```
1. Подготовка кабеля: С помощью обжимного инструмента была снята внешняя оболочка кабеля UTP на длину 12,5 мм.
2. Расположение жил: Жилы были расплетены и выровнены в соответствии с выбранной схемой заделки (например, 568B).
3. Монтаж разъема: Подготовленные жилы вставлены в коннектор до упора. Коннектор помещен в гнездо обжимного инструмента и зажат до фиксации контактов, которые прорезали изоляцию жил.
4. Установка сетевой карты: Сетевой адаптер установлен в разъем PCI на системной плате и сконфигурирован ОС с помощью технологии Plug-and-Play.
5. Тестирование: Готовый патч-корд проверен с помощью LAN-тестера на корректность соединения всех жил.
```

## Ответы на контрольные вопросы

### 1. Какие сетевые кабели использует технология Ethernet? Что такое кабель UTP?

```
1. Используются коаксиальные кабели (10Base-5, 10Base-2), витая пара (10Base-T, 100Base-TX) и оптоволокно.
2. UTP (Unshielded Twisted Pair) — неэкранированная витая пара.
3. Достоинства: дешевизна, простота монтажа, достаточная скорость. Недостатки: чувствительность к электромагнитным помехам (из-за отсутствия экрана)
```

### 2. Что такое сетевые устройства MDI и MDIX? Для соединения каких устройств необходим «перекрестный» кабель?

```
1. MDI — разъем сетевого адаптера (компьютера); MDIX — разъем порта концентратора/коммутатора.
2. Перекрестный кабель нужен для соединения однотипных устройств: MDI-MDI (компьютер-компьютер) или MDIX-MDIX (коммутатор-коммутатор)
```

### 3. Почему при монтаже вилки RJ-45 на кабель нет необходимости снимать изоляцию с отдельных жил?

```
Потому что при обжиме металлические контакты вилки утопляются внутрь, сами прорезают изоляцию жил и обеспечивают надежный контакт
```

### 4. Что такое «нуль-модемный» кабель и для каких целей он применяется?

```
Это вариант перекрестного (кроссового) кабеля. Он применяется для непосредственного соединения двух компьютеров через сетевые адаптеры без использования коммутатора
```

### 5. Каким образом однозначно идентифицируются сетевые адаптеры? С какой целью введена возможность изменения MAC-адреса?

```
1. С помощью MAC-адреса — уникального 48-битного серийного номера.
2. Возможность изменения введена для гибкости настройки сети, например, когда провайдер ограничивает доступ по конкретному адресу.
```

### 6. В чем заключается процесс конфигурирования сетевой платы? Какие параметры настраиваются?

```
В настройке свободных ресурсов: адреса ввода-вывода (In/Out port) и номера прерывания (IRQ). Современные карты делают это автоматически через Plug-and-Play
```

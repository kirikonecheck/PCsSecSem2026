# Практическая работа №12
## Настройка, обновление BIOS

## Цель работы

Получение практических навыков настройки параметров BIOS для управления производительностью системы, энергопотреблением, загрузкой и периферийными устройствами.

### Bios
```
BIOS (Basic Input/Output System) расшифровывается как Базовая система ввода-вывода.

Это набор микропрограмм, входящих в состав системного программного обеспечения, которые предназначены для доступа к аппаратной части компьютера и подключённым к нему устройствам.

В персональных компьютерах BIOS представляет собой совокупность микропрограмм, записанных в микросхему EEPROM (энергонезависимое программируемое ПЗУ). Данные микропрограммы обеспечивают начальную загрузку компьютера и последующий запуск операционной системы.
```
---

## Выполненные настройки

### 1. Установка системного времени

Установлено системное время **23:59:59**.

**Раздел BIOS:** `Main → System Time`

---

### 2. Установка системной даты

Установлена системная дата **1 апреля 2009 года**.

**Раздел BIOS:** `Main → System Date`

---

### 3. Настройка задержки опроса SATA-устройств

Установлена задержка перед опросом SATA-устройств — **20 секунд**. Данная настройка применяется при использовании медленных или старых накопителей, которым требуется дополнительное время для выхода на рабочий режим.

**Раздел BIOS:** `Main → SATA Configuration → Hard Disk Pre-Delay`

---

### 4. Разгон центрального процессора

Частота процессора увеличена до **3325 МГц** (FSB **350 МГц**) при неизменном множителе **9,5**. Повышение тактовой частоты позволяет увеличить вычислительную производительность системы.

**Раздел BIOS:** `Advanced → JumperFree Configuration → FSB Frequency`

---

### 5. Настройка напряжения северного моста

Напряжение питания северного моста повышено до **1,55 В**. Это требуется для обеспечения стабильной работы системы в условиях разгона процессора и оперативной памяти.

**Раздел BIOS:** `Advanced → JumperFree Configuration → North Bridge Voltage`

---

### 6. Отключение USB-контроллера

USB-контроллер отключён. Данная мера позволяет ограничить подключение внешних накопителей и повысить информационную безопасность.

**Раздел BIOS:** `Advanced → USB Configuration → USB Functions → Disabled`

---

### 7. Отключение встроенной сетевой карты

Встроенная сетевая карта (LAN) отключена. Применяется при её неисправности либо для изоляции компьютера от сети.

**Раздел BIOS:** `Advanced → Onboard Devices Configuration → Onboard PCIE Gbe LAN → Disabled`

---

### 8. Настройка поведения при потере питания

Установлен режим автоматического включения компьютера после восстановления электропитания. Используется для серверов и систем, работающих в автоматическом режиме без участия оператора.

**Раздел BIOS:** `Power → APM Configuration → Restore on AC Power Loss → Power On`

---

### 9. Активация удалённого включения (Wake-on-Modem)

Активирована возможность включения компьютера сигналом от модема из режима Soft Off. Позволяет удалённо запускать систему.

**Раздел BIOS:** `Power → APM Configuration → Power On By External Modem → Enabled`

---

### 10. Настройка приоритета загрузки

Первым загрузочным устройством установлен жёсткий диск `HDD:PM-Hitachi HDT`. Порядок загрузки определяет, с какого носителя система будет запускаться в первую очередь.

**Раздел BIOS:** `Boot → Boot Device Priority → 1st Boot Device`

---

## Результат

Все заданные параметры BIOS сконфигурированы. Настройки сохранены, система готова к работе в установленных режимах.

## Вывод

В ходе работы освоены следующие возможности BIOS:

- управление системным временем и датой;
- настройка задержек опроса SATA-устройств;
- разгон процессора с корректировкой напряжения северного моста;
- отключение USB-контроллера и встроенной сетевой карты;
- конфигурирование поведения при пропадании питания;
- активация удалённого включения по сигналу модема;
- изменение порядка загрузки загрузочных устройств.

Полученные навыки позволяют гибко настраивать аппаратную часть компьютера под конкретные задачи, повышать производительность и обеспечивать необходимый уровень безопасности.

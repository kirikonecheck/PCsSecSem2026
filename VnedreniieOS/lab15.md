# Лабораторная работа №15
## Тема: Настройка и обновление операционной системы Windows

**Цель работы:** Изучение практических механизмов конфигурирования параметров обновления и управления процессом установки обновлений в ОС семейства Windows.

---

## 1. Теоретические основы

### 1.1. Классификация обновлений по степени важности

Все обновления для Windows подразделяются на четыре категории в зависимости от их критичности и назначения:

| Категория | Характеристика | Режим установки |
| :-------- | :------------- | :-------------- |
| **Важные (Critical)** | Обеспечивают защиту системы от угроз, закрывают уязвимости и повышают общую надёжность. Требуют незамедлительной установки. | Обычно загружаются и инсталлируются автоматически через службу Windows Update |
| **Рекомендуемые (Recommended)** | Исправляют некритичные ошибки, оптимизируют производительность и устраняют мелкие сбои. | Могут устанавливаться как автоматически, так и по выбору пользователя (зависит от настроек) |
| **Необязательные (Optional)** | Включают обновлённые драйверы оборудования и дополнительные компоненты от Microsoft. | Устанавливаются исключительно вручную по инициативе пользователя |
| **Основные (Feature Updates)** | Крупные версионные обновления, которые приносят новые функциональные возможности и изменения в интерфейсе. | Устанавливаются по решению пользователя или администратора |

---

### 1.2. Типы обновлений по функциональному назначению

| Тип | Описание |
| :-- | :------- |
| **Обновление безопасности** | Исправляет обнаруженные уязвимости в продуктах Microsoft. Ранжируется по уровню угрозы: критический, важный, средний или низкий. |
| **Критическое обновление** | Устраняет серьёзные ошибки в работе программ, которые не связаны напрямую с безопасностью, но могут привести к сбоям. |
| **Пакет обновлений (Service Pack)** | Крупный накопительный сборник, включающий все ранее выпущенные исправления, улучшения и иногда новые функции. Является проверенным и стабильным комплексным решением. |

## 2. Порядок выполнения работы

### 2.1. Настройка Центра обновления Windows 10

**2.1.1. Проверка наличия доступных обновлений**

Для проверки актуальности системы необходимо:
1. Перейти в меню **Пуск → Параметры (шестерёнка) → Обновление и безопасность**.
2. Нажать кнопку **«Проверка наличия обновлений»**.

> **Примечание:** При возникновении ошибки подключения необходимо проверить сетевые настройки виртуальной машины либо обратиться за консультацией к преподавателю.

**2.1.2. Фиксация обязательных обновлений**

В интерфейсе Центра обновления отображаются все обновления, ожидающие установки. Необходимо зафиксировать перечень предлагаемых **важных и рекомендуемых** обновлений, включая их коды и краткие описания.

**2.1.3. Просмотр необязательных обновлений**

Необязательные обновления доступны по ссылке **«Просмотр необязательных обновлений»** (в некоторых версиях — «Дополнительные обновления»). В этом разделе представлены:
- обновления драйверов для оборудования;
- дополнительные языковые пакеты;
- другие необязательные компоненты.

Необходимо зафиксировать список доступных необязательных обновлений.

**2.1.4. Установка обновлений и проверка журнала**

После запуска процесса загрузки и установки обновлений необходимо дождаться их завершения. Для контроля установленных обновлений используется **Журнал обновлений**, доступный по пути:
`Параметры → Обновление и безопасность → Центр обновления Windows → Просмотр журнала установленных обновлений`.

В отчёте необходимо указать:
- перечень установленных обновлений;
- дату и время установки;
- тип каждого обновления.

### 2.2. Отключение автоматического обновления Windows 10

Для полного отключения механизма автоматической загрузки и установки обновлений используется редактор локальной групповой политики.

**2.2.1. Запуск редактора**
- Нажать сочетание клавиш `Win + R`.
- Ввести команду `gpedit.msc` и нажать `Enter`.

**2.2.2. Переход к нужному разделу**
В окне редактора последовательно раскрыть ветки:
`Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Центр обновления Windows`.

Найти параметр с названием **«Настройка автоматического обновления»** и дважды кликнуть по нему.

**2.2.3. Отключение обновлений**
В открывшемся окне:
- Установить переключатель в положение **«Отключено»**.
- Нажать `Применить` → `OK`.

После выполнения этих действий операционная система прекратит автоматическую проверку и установку обновлений. Необходимо открыть Центр обновления Windows и зафиксировать произошедшие изменения в интерфейсе.

---

### 2.3. Установка обновлений из локальной папки вручную

В рамках работы требуется установить заранее подготовленные обновления, размещённые в сетевом каталоге.

**2.3.1. Доступ к папке с обновлениями**
На виртуальной машине открыть проводник и в адресной строке ввести сетевой путь: `\\kbastrikin`

Из общего доступа необходимо скопировать файлы обновлений в локальную папку.

**2.3.2. Установка обновлений**
Запустить каждый файл обновления двойным кликом и следовать инструкциям мастера установки.

**2.3.3. Определение типа установленных обновлений**
Для получения информации о каждом обновлении используется официальный сайт каталога обновлений Microsoft:  
**http://www.catalog.update.microsoft.com**

В поисковую строку сайта вводится номер обновления (например, `KB5084066`). Результаты поиска позволяют определить:
- тип обновления (Security Update, Critical Update, и т.п.);
- версию .NET Framework или компонента;
- точный размер файла.

| Номер обновления | Тип / Классификация | Версия | Размер |
| :--------------- | :------------------ | :----- | :----- |
| KB5084066 | Обновление безопасности (Security Update) | .NET Framework 3.5, 4.7.2, 4.8 | 173,1 МБ |
| KB5073723 | Обновление безопасности (Security Update) | Сборка ОС 17763.8276 | 408,9 МБ |

### 2.4. Настройка Центра обновления как службы Windows

**2.4.1. Запуск оснастки «Службы»**
Перейти по пути:
`Панель управления → Администрирование → Управление компьютером → Службы и приложения → Службы`.

**2.4.2. Поиск службы Центра обновления**
В списке служб найти пункт **«Центр обновления Windows»** (Windows Update) и открыть его свойства (двойным кликом или через контекстное меню → Свойства).

**2.4.3. Изменение типа запуска**
В открывшемся окне:
- Перейти на вкладку **«Общие»**.
- В выпадающем списке **«Тип запуска»** выбрать значение **«Вручную»**.
- Нажать `Применить` → `OK`.

Это позволяет отключить автоматический запуск службы при старте системы и управлять ею вручную.

### 2.5. Предъявление результатов преподавателю

После выполнения всех этапов работы необходимо продемонстрировать преподавателю:
- выполненные настройки Центра обновления;
- журнал установленных обновлений;
- настроенную службу Windows Update с типом запуска «Вручную».

## 3. Контрольные вопросы

### Вопрос 1. Что такое обновление программного обеспечения?
**Обновление** — это целенаправленное изменение программного продукта, которое может включать исправление выявленных ошибок, устранение уязвимостей, улучшение производительности или добавление новых функций. Обновления выпускаются для повышения стабильности, безопасности и удобства работы системы.

---

### Вопрос 2. Основные типы обновлений в Windows

| Тип обновления | Назначение |
| :------------- | :--------- |
| **Обновления безопасности** | Закрывают обнаруженные уязвимости, защищают систему от вредоносного ПО и несанкционированного доступа |
| **Исправления (Bug Fixes)** | Устраняют ошибки в работе приложений и системных компонентов, повышают стабильность |
| **Функциональные обновления (Feature Updates)** | Добавляют новые возможности, изменяют интерфейс и функциональность системы |
| **Обновления драйверов** | Обеспечивают корректную работу оборудования (видеокарты, сетевые адаптеры, принтеры и т.д.) |

---

### Вопрос 3. Что представляет собой Центр обновления Windows?
**Центр обновления Windows (Windows Update)** — это встроенная системная служба, которая отвечает за автоматический поиск, загрузку и установку актуальных обновлений для операционной системы и сопутствующих продуктов Microsoft. Центр обновления взаимодействует с удалёнными серверами корпорации Microsoft, сравнивает текущую версию системы с доступными обновлениями и предлагает пользователю или администратору необходимые исправления.

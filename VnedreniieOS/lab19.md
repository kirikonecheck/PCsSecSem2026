## 1. Теоретические сведения

Операционная система непрерывно отслеживает происходящие в ней процессы и автоматически регистрирует наиболее важные события в специальных системных логах, которые в Windows называются **журналами событий**.

Основное предназначение журналов событий — сбор данных, которые могут быть использованы для диагностики и устранения неисправностей в работе системы, программного обеспечения и оборудования. В журналы записываются не только критические ошибки, но также предупреждения и успешные операции (например, установка программы или подключение к сети).

Физически журналы событий представляют собой набор файлов в формате **EVTX**, расположенных в системной папке:

%SystemRoot%/System32/Winevt/Logs

Данные файлы имеют бинарный формат и не могут быть открыты стандартными текстовыми редакторами.

Для просмотра журналов событий в системе предусмотрена штатная утилита **eventvwr.msc**. Запуск возможен из Панели управления (*Администрирование → Просмотр событий*) или через выполнение команды `eventvwr.msc` в окне «Выполнить» (`Win + R`).

Интерфейс утилиты содержит следующие основные области:
- **Левая панель** — дерево журналов, сгруппированных по разделам;
- **Центральная панель** — список событий выбранного журнала;
- **Правая панель** — доступные действия;
- **Нижняя панель** — подробные сведения о выбранном событии.

Наибольший практический интерес представляет раздел **«Журналы Windows»**, который включает следующие категории:

| Категория | Описание |
|-----------|----------|
| **Система** | События, генерируемые системными компонентами (драйверами и модулями Windows) |
| **Приложения** | Записи, создаваемые установленными программами |
| **Безопасность** | Сведения о безопасности (входы в учётные записи, изменение разрешений и т.д.) |
| **Установка** | События, связанные с установкой обновлений и программного обеспечения |
| **Перенаправленные события** | События, полученные с других компьютеров |

Очистка журналов может быть выполнена несколькими способами: через оснастку eventvwr (контекстное меню журнала → «Очистить журнал»), с помощью командной строки или PowerShell.

## 3. Контрольные вопросы

### 1. Что такое журналы событий Windows?

Журналы событий Windows — это системные логи, в которые операционная система и установленные приложения автоматически записывают информацию о значимых событиях: ошибках, предупреждениях, успешных операциях и действиях, связанных с безопасностью. Журналы используются для мониторинга состояния системы, диагностики неисправностей и анализа происходящих в системе процессов.

### 2. Каково физическое расположение файлов журналов?

Файлы журналов событий в формате `.evtx` хранятся по следующему пути:

%SystemRoot%/System32/Winevt/Logs

### 3. Перечислите основные и дополнительные категории журналов Windows.

**Основные категории (раздел «Журналы Windows»):**

- **«Система»** — события от драйверов и системных компонентов Windows;
- **«Приложения»** — события, генерируемые установленными программами;
- **«Безопасность»** — события, связанные с безопасностью (аутентификация, авторизация, изменение прав).

**Дополнительные категории:**

- **«Установка»** — события об установке обновлений и программного обеспечения;
- **«Перенаправленные события»** — события, полученные от других компьютеров в сети.

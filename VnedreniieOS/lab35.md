# Практическая работа
## Тема: Освоение Midnight Commander — работа с файлами и каталогами в Linux

**Цель занятия:** Получение практических навыков работы с файловым менеджером Midnight Commander (MC) для управления файловой системой в операционной системе GNU/Linux.

---

## 1. Теоретические сведения

Midnight Commander (mc) — это мощный консольный файловый менеджер с двухпанельным интерфейсом, позволяющий выполнять все основные операции с файлами и каталогами: навигацию, копирование, перемещение, удаление, редактирование, поиск, а также подключаться к удалённым серверам по FTP и SSH.

**Основные возможности MC:**
- две панели для удобного сравнения и копирования;
- встроенный просмотрщик и текстовый редактор;
- поддержка FTP и SFTP;
- работа с архивами как с обычными папками;
- встроенная командная строка;
- настраиваемая сортировка и фильтрация.

---

## 2. Подготовка рабочей среды

Для выполнения работы используется компьютер с установленной операционной системой **Ubuntu** или **Debian** с графической средой **GNOME**.

1. Включить компьютер и авторизоваться под выданными учётными данными.
2. Открыть эмулятор терминала:
   - сочетание клавиш `Ctrl + Alt + T`;
   - или через меню `Applications → Accessories → Terminal`.
3. Для оформления отчёта использовать **LibreOffice Writer** (`Applications → Office → LibreOffice Writer`).

---

## 3. Порядок выполнения работы

### 3.1. Запуск Midnight Commander

В терминале ввести команду:
```bash
mc

Нажать Enter. Развернуть окно на весь экран для удобства работы.

Обратить внимание на интерфейс:

две панели с файлами;

верхнее меню (доступно по F9);

нижняя строка с подсказками по функциональным клавишам.

Сделать скриншот окна MC и сохранить в отчёте.
```

### 3.2. Настройка отображения содержимого панелей
Последовательно выполнить следующие действия, фиксируя каждый шаг скриншотом:

#### 3.2.1. Режим «Дерево»

Открыть меню Right (или нажать F9, затем R).

Выбрать Tree (или нажать T).

Изучить структуру каталога /etc в виде дерева.

#### 3.2.2. Информация об объекте

Открыть меню Right → Info (или F9 → R → Ctrl+X → I).

На левой панели выделить любой файл или папку — справа отобразится подробная информация о нём (размер, права, владелец, время изменения).


#### 3.2.3. Быстрый просмотр
Открыть меню Right → Quick View (или F9 → R → Ctrl+X → Q).

На левой панели выбрать текстовый файл, например /etc/fstab — его содержимое сразу отобразится на правой панели.

#### 3.2.4. Возврат к обычному режиму
Открыть меню Right → File listing (или F9 → R → G).

### 3.3. Сортировка объектов
Для сортировки используется меню Right → Sort order (F9 → R → S).

#### 3.3.1. Сортировка по размеру
В окне сортировки выбрать Size (клавиша S), нажать OK.

Перейти в каталог /etc — самый большой файл окажется внизу списка.

#### 3.3.2. Сортировка по времени изменения
В окне сортировки выбрать Modify Time (клавиша M), нажать OK.

Внизу списка будет файл с самой свежей датой изменения.

#### 3.3.3. Сортировка по имени
В окне сортировки выбрать Name (клавиша N), нажать OK.

В конце списка окажется файл, начинающийся с буквы, близкой к концу алфавита (например, z).

### 3.4. Просмотр, редактирование и создание каталогов
#### 3.4.1. Просмотр файла
Выделить текстовый файл (например, /etc/fstab).

Нажать F3 (или File → View).

#### 3.4.2. Создание нового файла
Перейти в домашний каталог (cd ~ или ~ в адресной строке).

Нажать Shift + F4.

Ввести произвольный текст.

Сохранить файл клавишей F2, указать имя newfile, нажать OK.

Закрыть редактор F10.

#### 3.4.3. Редактирование файла
Выделить созданный файл newfile.

Нажать F4 (или File → Edit).

Добавить текст, сохранить F2, закрыть F10.

#### 3.4.4. Создание каталога
Нажать F7 (или File → Mkdir).

Ввести имя new_dir, нажать OK.

Установить курсор на созданную папку.

### 3.5. Копирование файлов и папок
Одна панель служит источником, другая — приёмником. Переключение между панелями выполняется клавишей Tab или мышью.

На левой панели открыть корневой каталог /.

На правой панели открыть каталог /tmp.

На левой панели выделить папку etc.

Нажать F5 (или File → Copy).

В открывшемся окне обратить внимание на опцию Preserve attributes (сохранять атрибуты — аналог cp -p).

Нажать OK и дождаться окончания копирования.

На правой панели перейти в скопированную папку и сделать скриншот.

### 3.6. Перемещение и переименование
На обеих панелях открыть каталог /tmp.

Выделить скопированную папку etc.

Нажать F6 (или File → Rename/Move).

При желании переименовать её в etc_new.

Нажать OK.

### 3.7. Удаление объектов
Выделить ненужный объект (например, папку etc_new).

Нажать F8 (или File → Delete).

Подтвердить удаление: сначала Yes, затем в следующем окне для рекурсивного удаления всех вложенных объектов выбрать All.

### 3.8. Поиск файлов и каталогов
Поиск вызывается через меню Command → Find file (F9 → C → F).

#### 3.8.1. Поиск по маске имени
Перейти в домашний каталог.

В поле File name: ввести *.png.

Снять галочку Search for content (искать только по имени).

Нажать OK.

После завершения поиска сделать скриншот с результатами.

#### 3.8.2. Поиск текста внутри файлов
Перейти в каталог /etc.

В поле File name: указать * (все файлы).

Поставить галочку Search for content.

В поле Content: ввести clock (или любое другое слово).

Нажать OK.

### 3.9. Создание символических ссылок
На обеих панелях перейти в /tmp.

Выделить любой файл.

Нажать File → Symlink (или F9 → F → S).

В строке Symbolic link filename: дописать в конец _link.

Нажать OK.

Обратить внимание — перед именем ссылки появится символ @.

Установить курсор на ссылку — в нижней части панели отобразится путь к исходному файлу.

### 3.10. Оценка занятого и свободного места
В правом нижнем углу каждой панели отображается информация: Доступно / Всего (в байтах и процентах).

Для определения размера каталогов выбрать Command → Show directory sizes (или нажать Ctrl + Space).

Перейти в /etc, отсортировать по размеру, затем выполнить команду — в столбце Size отобразится занимаемое место.

### 3.11. Подключение к FTP-серверу
В Midnight Commander встроен FTP-клиент.

Выбрать Left → FTP link (F9 → L → P).

В появившемся окне ввести ftp://mirror.yandex.ru.

Нажать OK.

На активной панели отобразится содержимое публичного FTP-сервера.

### 3.12. Подключение к SFTP-серверу через SSH
Выбрать Left → Shell link (F9 → L → S).

Ввести адрес сервера (по указанию преподавателя, либо server для теста).

Нажать OK.

На панели появится содержимое удалённого сервера.

### 3.13. Использование встроенной командной строки
В нижней части окна MC всегда доступна командная строка.

Ввести команду date и нажать Enter.

Нажать Ctrl + O — Midnight Commander временно скроется, и будет виден вывод команды.

Вернуться в MC повторным нажатием Ctrl + O.

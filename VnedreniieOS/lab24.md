## 1. Теоретические сведения

### 1.1. Концепция файловой системы

Основополагающий принцип ОС Linux — **«Всё есть файл»**. Файловая система имеет единую иерархическую структуру, напоминающую перевёрнутое дерево. Конечными узлами дерева являются файлы, а промежуточными — каталоги (папки).

- **Корневой каталог (`/`)** — вершина всей файловой системы.
- **Путь к файлу** — цепочка каталогов, разделённых косой чертой `/` (например, `/home/user/file.txt`).

### 1.2. Основные каталоги Linux и их назначение

| Каталог | Назначение |
|---------|------------|
| `/bin` | Основные системные утилиты и команды (доступны всем пользователям) |
| `/sbin` | Системные утилиты для администрирования (доступны суперпользователю) |
| `/boot` | Файлы для загрузки ОС и ядро Linux |
| `/dev` | Файлы устройств (диски, терминалы, мышь) |
| `/etc` | Конфигурационные файлы системы и программ |
| `/home` | Домашние каталоги пользователей |
| `/root` | Домашний каталог суперпользователя root |
| `/lib`, `/lib64` | Системные библиотеки для работы программ |
| `/media`, `/mnt` | Точки монтирования съёмных дисков и флешек |
| `/proc` | Виртуальная ФС с информацией о процессах и ядре |
| `/sys` | Информация об аппаратной части компьютера |
| `/tmp` | Временные файлы (очищаются при перезагрузке) |
| `/usr` | Пользовательские программы, документация и библиотеки |
| `/var` | Изменяемые данные: лог-файлы, базы данных, почта |

**Структура файловой системы (схема):**

```
[ / ] (Корень)
├── bin/
├── boot/
├── dev/
├── etc/
├── home/
│ └── user/
├── root/
└── var/
```


### 1.3. Типы файлов в Linux

При просмотре списка файлов командой `ls -l` первый символ строки определяет тип объекта:

| Символ | Тип |
|--------|-----|
| `-` | Обычный файл (текст, исполняемая программа, изображение) |
| `d` | Каталог (директория) |
| `l` | Символическая ссылка (ярлык) |
| `c` | Символьное устройство |
| `b` | Блочное устройство |

### 1.4. Права доступа и безопасность

Каждый объект в Linux имеет:
- **Владельца** (User)
- **Группу** (Group)
- **Права для остальных пользователей** (Others)

**Три типа прав:**

| Право | Обозначение | Для файла | Для каталога |
|-------|-------------|-----------|--------------|
| Read | `r` | Чтение содержимого | Просмотр списка файлов |
| Write | `w` | Запись/изменение | Создание/удаление файлов |
| Execute | `x` | Запуск программы | Вход в каталог |

**Формат отображения прав (`ls -l`):**

```
rwx r-x r--
│ │ │
│ │ └── права для остальных (Others): только чтение
│ └────── права для группы (Group): чтение и выполнение
└────────── права для владельца (User): чтение, запись, выполнение
```


**Управление правами:**

| Команда | Назначение |
|---------|------------|
| `chmod [права] [файл]` | Изменение прав доступа (например, `chmod 755 script.sh`) |
| `chown [пользователь] [файл]` | Изменение владельца |

### 1.5. Ссылки (Связи) на файлы

Ссылки создают альтернативные имена для файлов:

| Тип | Описание | Команда |
|-----|----------|---------|
| **Жёсткая ссылка** | Указывает на тот же индексный дескриптор (inode). Удаление оригинала не уничтожает данные. | `ln файл ссылка` |
| **Символическая ссылка** | Ярлык, указывающий на путь к файлу. Ломается при удалении оригинала. | `ln -s файл ссылка` |

### 1.6. Создание и удаление файлов и каталогов

| Действие | Команда |
|----------|---------|
| Создание файла | `touch файл`, `echo > файл`, `nano файл` |
| Удаление файла | `rm файл` |
| Создание каталога | `mkdir каталог` |
| Удаление пустого каталога | `rmdir каталог` |
| Удаление каталога с содержимым | `rm -r каталог` |

### 1.7. Поиск по шаблону (Wildcards)

Для поиска файлов используются специальные символы:

| Символ | Описание |
|--------|----------|
| `*` | Любая строка любой длины |
| `?` | Один любой символ |
| `[...]` | Любой символ из указанного диапазона |

### 1.8. Просмотр пользователей системы

Команда для вывода списка активных пользователей:

```bash
who > users.txt
```

или

```bash
w > users.txt
```

## Практическая часть

### 2.1. Создание текстовых файлов
#### Созданы два текстовых файла, в которые помещена текстовая информация.

Использованные команды:
```bash
echo "Содержимое первого файла" > file1.txt
echo "Содержимое второго файла" > file2.txt
```

Результат: созданы файлы file1.txt и file2.txt с текстовым содержимым.
---

### 2.2. Объединение файлов

#### Выполнено объединение двух файлов в один. Просмотрено содержимое результирующего файла.

Использованные команды:

```bash
cat file1.txt file2.txt > merged.txt
cat merged.txt
```

Результат: создан файл merged.txt, содержащий объединённое содержимое обоих исходных файлов.
---

### 2.3. Создание каталога и перемещение файлов

#### Создан новый каталог, в который перемещены созданные файлы.

Использованные команды:

```bash
mkdir new_folder
mv *.txt new_folder/
```
Результат: создан каталог new_folder, все файлы с расширением .txt перемещены в него.

### 2.4. Просмотр полной информации о файлах

#### Просмотрена полная информация о файлах с анализом прав доступа.

Использованная команда:
```bash
ls -l new_folder/
```
Результат: выведена подробная информация о файлах, включая права доступа, владельца, группу, размер и дату создания.

### 2.5. Изменение прав доступа

#### Добавлено право выполнения для группы и остальных пользователей.

Использованная команда:

```bash
chmod go+x new_folder/file1.txt
```
Результат: для группы и остальных пользователей добавлено право на выполнение файла.

### 2.6. Просмотр структуры каталогов

#### Выполнен рекурсивный просмотр структуры каталогов.

Использованная команда:

```bash
ls -R
```
Результат: выведена полная структура всех каталогов и файлов в текущей директории и поддиректориях.

### 2.7. Создание ссылок

#### Выполнено создание жёстких и символических ссылок на файлы.

Использованные команды:
```bash
ln new_folder/file1.txt hard_link
ln -s new_folder/file1.txt sym_link
```
Результат: созданы жёсткая ссылка hard_link и символическая ссылка sym_link на файл file1.txt.

### 2.8. Вывод списка пользователей

#### Список активных пользователей сохранён в файл.

Использованная команда:
```bash
who > users.txt
```
Результат: создан файл users.txt с информацией о пользователях, активных в данный момент.

## 3. Контрольные вопросы

### 1. Что означает принцип «Всё есть файл» в Linux?
```
Это фундаментальная концепция, согласно которой все объекты в системе (обычные файлы, каталоги, устройства, сетевые сокеты, процессы) 
представлены в виде файлов и могут быть доступны через единый интерфейс файловой системы. Это упрощает взаимодействие с системой и позволяет 
использовать одни и те же инструменты для работы с разными типами объектов.
```

### 2. Какие типы файлов существуют в Linux?

|Тип	|Обозначение	|Описание|
|-------|---------------|--------|
|Обычный файл	|-	|Текстовые, исполняемые, изображения и т.д.|
|Каталог	|d	|Содержит другие файлы и каталоги|
|Символическая ссылка	|l	|Ярлык на другой файл|
|Символьное устройство	|c	|Устройства с последовательным доступом (терминалы)|
|Блочное устройство	|b	|Устройства с блочным доступом (диски)|

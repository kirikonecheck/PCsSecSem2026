# Схема видов тестирования велосипеда

|Категория | Тип  тестирования | Краткое описание и примеры |
| :--- | :--- | :--- |
| **По уровню/объекту** | **Компонентное/модульное** | Тестирование отдельных частей: тормозной системы, переключателя скоростей, амортизатора, колеса в сборе. |
| | **Интеграционное** | Проверка взаимодействия компонентов: тормозных ручек с калиперами/колодками, системы переключения (ручка-тросик-переключатель), сборки рамы с вилкой и колёсами. |
| | **Функциональное** | Проверка соответствия функций требованиям: переключение передач, работа тормозов, регулировка седла и руля, работа фар/динамо. |
| **По подходу/методологии** | **Тестирование "чёрного ящика"** | Тестирование без углубления во внутреннее устройство. Проверка: велосипед разгоняется, когда крутишь педали, и замедляется, когда жмёшь на тормоз. |
| | **Валидация**  | Удобен ли для ежедневных поездок по городу, подходит ли для целевого роста/веса. |
| | **Верификация** | Соответствие техническим спецификациям и стандартам: применялись ли заявленные материалы, выдержаны ли моменты затяжки. |
| | **Негативное тестирование** | Проверка на нештатные ситуации и некорректные данные: попытка переключиться на несуществующую передачу, резкое торможение на мокром асфальте, удар по колесу для проверки обода "восьмёрки". |
| **По нефункциональным характеристикам** | **Тестирование производительности** | Проверка скоростных и динамических характеристик: разгон до 30 км/ч, эффективность разгона с места. |
| | **Нагрузочное/стресс-тестирование** | Эксплуатация в условиях, превышающих нормальные: движение с нагрузкой 150 кг вместо заявленных 120 кг, прыжки на бордюрах на шоссейном велосипеде. |
| | **Тестирование удобства использования** | Оценка эргономики и простоты освоения: легко ли отрегулировать высоту седла, интуитивны ли переключатели, удобна ли посадка для длительной поездки. |
| | **Тестирование совместимости** | Совместимость с аксессуарами и стандартами: подходят ли стандартные крылья, держатели для бутылок, совместимость каретки с системой шатунов. |
| | **Тестирование безопасности** | Проверка защищённости от краж и надежности для пользователя: надежность замка (при его тестировании), устойчивость противоугонной системы, прочность крепления колёс на эксцентриках. |
| | **Тестирование пользовательского интерфейса** | Тестирование интерфейса взаимодействия: читаемость дисплея на велокомпьютере, тактильность и понятность кнопок, видимость световых индикаторов |
| **По сценариям и источникам данных** | **Тестирование точек входа** | Тестирование с фокусом на начальные действия пользователя: первая сборка, регулировка под себя, начало первой поездки. |
| | **Тестирование документации** | Проверка инструкции по сборке, мануала по обслуживанию: соответствуют ли шаги реальному процессу, все ли детали на схеме пронумерованы. |
|**По времени и исполнителю** | **Автоматизированное** | Использование стендов и роботов: автоматический стенд для проверки тормозов (циклическое нажатие), робот для имитации долговечности педалей. |
| | **Бета-тестирование** | Полевые испытания силами ограниченной группы реальных пользователей перед массовым выпуском: выдача прототипов курьерам или энтузиастам для еждневного использования на 1 месяц. |

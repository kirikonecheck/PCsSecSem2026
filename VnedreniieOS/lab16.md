# Практическая работа №16
## Тема: Управление групповыми политиками в Windows 10

**Цель работы:** Изучение механизмов настройки локальных групповых политик для управления параметрами операционной системы, ограничениями пользователей и интерфейсом Windows.

---

## 1. Теоретическая часть

### 1.1. Что такое групповые политики?

**Групповые политики (Group Policies)** — это инструмент административного управления, представляющий собой совокупность правил и настроек, определяющих поведение операционной системы, параметры рабочей среды пользователей и ограничения доступа к различным функциям. Групповые политики позволяют централизованно или локально настраивать:

- интерфейс и поведение рабочего стола;
- параметры безопасности;
- права пользователей;
- доступ к системным утилитам и компонентам;
- многие другие аспекты работы ОС.

Простыми словами, групповые политики — это инструкция для Windows: «что разрешено», «что запрещено» и «как это должно выглядеть».

---

### 1.2. Запуск редактора локальной групповой политики

Для открытия оснастки «Редактор локальной групповой политики» необходимо выполнить следующие действия:

1. Нажать сочетание клавиш `Win + R` либо выбрать в меню **Пуск** команду **Выполнить**.
2. В появившемся диалоговом окне ввести команду `gpedit.msc`.
3. Нажать клавишу **Enter** или кнопку **OK**.

После выполнения этих действий откроется окно **Редактор локальной групповой политики**. Приставка «локальный» означает, что изменения применяются только к текущему компьютеру, а не распространяются по сети на другие машины.

---

### 1.3. Структура окна редактора

Окно редактора состоит из двух основных панелей:

- **Левая панель (дерево консоли)** — содержит иерархическую структуру категорий политик, разделённых на две главные группы:
  - **Конфигурация компьютера** — политики, применяемые ко всем пользователям независимо от их учётной записи, активируются ещё до входа в систему.
  - **Конфигурация пользователя** — политики, применяемые к текущему пользователю после его входа в систему.

- **Правая панель** — отображает список политик, относящихся к выбранной в левой панели категории. Для каждой политики указываются её название и текущее состояние.

**Информация о политике:**
- **Столбец «Параметр»** — отображает название конкретной политики.
- **Столбец «Состояние»** — показывает статус политики: включена, отключена или не задана.

Для просмотра подробного описания политики достаточно кликнуть по ней. Если описание не отображается, необходимо переключиться на вкладку **«Расширенный»** в нижней части окна.

---

### 1.4. Настройка параметров политики

Для изменения состояния политики необходимо дважды кликнуть по ней левой кнопкой мыши. Открывающееся окно настройки может различаться в зависимости от типа политики:

**Для простых политик** доступны три варианта состояния:

| Состояние | Описание |
| :-------- | :------- |
| **Не задано** | Политика не применяется, система работает по умолчанию (рекомендуется, если не требуется принудительное управление) |
| **Включить** | Политика активна, применяются заданные в ней ограничения или настройки |
| **Отключить** | Политика принудительно деактивирована |

**Для сложных политик** после выбора состояния **«Включить»** могут активироваться дополнительные поля для ввода параметров:
- пути к папкам;
- списки разрешённых или запрещённых приложений;
- числовые значения лимитов;
- другие специфические настройки.

---

### 1.5. Фильтрация политик

Ввиду того, что в редакторе присутствует более 3000 параметров, ручной поиск нужной настройки крайне затруднителен. Для упрощения процесса поиска используются:

- **Ветвь «Все параметры»** — расположена в разделе *Административные шаблоны* и отображает все доступные политики в виде единого списка без разбивки по категориям.
- **Фильтрация** — позволяет сузить список до подходящих пунктов на основе ключевых слов.

**Алгоритм фильтрации (на практическом примере):**

1. В левой панели выбрать путь: `Конфигурация пользователя → Административные шаблоны → Все параметры`.
2. В верхнем меню выбрать **Действие → Параметры фильтра** (либо воспользоваться кнопкой на панели инструментов).
3. В открывшемся диалоговом окне убедиться, что установлен флажок **«Включить фильтры по ключевым словам»**.
4. В поле **«Фильтры по словам»** ввести искомое слово или словосочетание (например, слово **«мест»** для поиска политики, связанной с панелью мест).
5. В раскрывающемся списке выбрать один из уровней соответствия:

| Уровень | Описание |
| :------ | :------- |
| **Любой** | Отображаются политики, содержащие хотя бы один из введённых терминов |
| **Все** | Отображаются политики, содержащие все введённые термины в любом порядке |
| **Точный** | Отображаются политики, текст которых полностью совпадает с поисковым запросом |

6. С помощью флажков в разделе **«В»** указать, где именно производить поиск:
   - **Заголовок параметра политики** — по названиям;
   - **Текст справки** — по описаниям политик;
   - **Комментарий** — по пользовательским примечаниям.

7. Нажать кнопку **OK** для применения фильтра.
8. Активировать фильтр через меню **Действие → Фильтр** или кнопку на панели инструментов.

> **Результат:** в правой панели останутся только те политики, которые соответствуют заданным условиям фильтрации.

## 2. Практическое задание

### 2.1. Настройка окна безопасности Windows

При нажатии сочетания `Ctrl + Alt + Delete` в Windows появляется окно безопасности, содержащее следующие команды:

| Команда | Назначение |
| :------ | :--------- |
| **Блокировать компьютер** | Скрывает рабочий стол и отображает экран блокировки. Для разблокировки требуется ввод пароля. Альтернативный быстрый способ — `Win + L`. |
| **Сменить пользователя** | Позволяет войти под другой учётной записью, не закрывая сеанс текущего пользователя. |
| **Выйти из системы** | Завершает текущий сеанс и возвращает к экрану приветствия. |
| **Сменить пароль** | Открывает окно для смены пароля текущей учётной записи. |
| **Запустить диспетчер задач** | Открывает Диспетчер задач для управления процессами и производительностью. |

Все указанные команды, кроме **«Сменить пользователя»**, могут быть скрыты или отключены с помощью групповых политик. Это полезно, если требуется ограничить возможности пользователей или упростить интерфейс.

**Алгоритм настройки:**

1. Открыть редактор локальной групповой политики (`gpedit.msc`).
2. В левой панели последовательно раскрыть ветви:  
   `Конфигурация пользователя → Административные шаблоны → Система → Варианты действий после нажатия CTRL+ALT+DEL`.
3. Для каждой нужной политики выполнить двойной клик и установить состояние **«Включить»**:

| Политика | Отключаемый элемент |
| :------- | :------------------ |
| Запретить изменение пароля | Кнопка **Сменить пароль** |
| Запретить блокировку компьютера | Кнопка **Блокировать компьютер** |
| Удалить диспетчер задач | Кнопка **Запустить диспетчер задач** |
| Запретить завершение сеанса | Кнопка **Выйти из системы** |

4. Нажать **OK** после каждого изменения.

---

**Настройка через реестр (альтернативный способ):**

Для отключения кнопок **Сменить пароль**, **Блокировать компьютер** и **Диспетчер задач** необходимо открыть редактор реестра (`regedit`) и перейти к ключу:

`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System`

Затем изменить значения соответствующих параметров на `0`:

| Параметр | Отключаемый элемент |
| :------- | :------------------ |
| `DisableChangePassword` | Сменить пароль |
| `DisableLockWorkstation` | Блокировать компьютер |
| `DisableTaskMgr` | Диспетчер задач |

Для удаления кнопки **Выйти из системы** используется другой ключ:

`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer`

Значение параметра `NoLogoff` необходимо установить в `1`.

---

### 2.2. Настройка панели мест

В левой части диалоговых окон **Сохранить как** и **Открыть** в классических приложениях отображается панель с ярлыками часто используемых папок: **Недавние места**, **Рабочий стол**, **Библиотеки**, **Компьютер**, **Сеть**. Эта область называется **панелью мест**.

Если вы регулярно работаете с несколькими проектами, можно настроить панель мест так, чтобы в ней отображались пользовательские папки. Это значительно ускоряет навигацию.

**Настройка через групповые политики:**

1. Открыть редактор локальной групповой политики.
2. Перейти в ветвь:  
   `Конфигурация пользователя → Административные шаблоны → Компоненты Windows → Проводник Windows → Общее диалоговое окно открытия файлов`.
3. Дважды кликнуть по политике **«Элементы, отображаемые в панели мест»**.
4. Установить переключатель в положение **«Включить»**.
5. В появившихся текстовых полях **Элемент 1** – **Элемент 5** указать пути к нужным папкам (локальные или сетевые).
6. Нажать **OK** для применения.

---

**Настройка через реестр (альтернативный способ):**

1. Открыть редактор реестра (`regedit`).
2. Перейти к ключу: `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\`.
3. Создать новый раздел с именем `comdlg32`:  
   `Правка → Создать → Раздел` → ввести `comdlg32` → `Enter`.
4. Внутри раздела `comdlg32` создать ещё один раздел: `Placesbar`.
5. В разделе `Placesbar` создать строковый параметр (`Правка → Создать → Строковый параметр`) с именем `Place0`.
6. Открыть созданный параметр и указать путь к папке в поле «Значение».
7. Повторить шаги 5–6 для дополнительных папок с именами `Place1`, `Place2`, `Place3`, `Place4` (максимум 5 элементов).

> **Дополнительно:** Чтобы полностью скрыть панель мест, используется политика **«Скрыть панель адресов из общих диалогов открытия файлов»** (находится там же, где и предыдущая политика). Установите её в состояние **«Включить»**.

---

### 2.3. Увеличение размера списка недавних документов

По умолчанию в меню **Пуск** пункт «Недавние документы» отображает до 15 последних файлов, с которыми работал пользователь. При необходимости количество отображаемых документов можно увеличить.

**Настройка через групповые политики:**

1. Открыть редактор локальной групповой политики.
2. Перейти в ветвь:  
   `Конфигурация пользователя → Административные шаблоны → Компоненты Windows → Проводник Windows`.
3. Найти политику **«Максимальная длина списка "Недавние документы"»** и дважды кликнуть по ней.
4. Установить переключатель в положение **«Включить»**.
5. В счётчике **«Максимальная длина списка "Недавние документы"»** указать требуемое значение (от 1 до 9999 документов).
6. Нажать **OK** для применения.

> **Примечание:** При установке значения, превышающего вертикальный размер экрана, Windows автоматически добавит кнопки прокрутки в верхней и нижней части списка.

---

### 2.4. Включение диалога слежения за завершением работы

В стандартной конфигурации при выборе команды **Завершение работы** Windows закрывает сеанс без дополнительных запросов (если нет несохранённых документов). Для административного учёта причин перезагрузок и остановок системы можно включить специальный диалог, позволяющий документировать событие.

**Настройка через групповые политики:**

1. Открыть редактор локальной групповой политики.
2. Перейти в ветвь:  
   `Конфигурация компьютера → Административные шаблоны → Система`.
3. Найти политику **«Отображать диалог слежения за завершением работы»** и дважды кликнуть по ней.
4. Установить переключатель в положение **«Включить»**.
5. В раскрывающемся списке **«Диалог слежения за завершением работы должен отображаться»** выбрать вариант **«Всегда»**.
6. Нажать **OK** для применения.

**Результат:** При попытке завершить работу будет появляться диалоговое окно с тремя элементами управления:

| Элемент | Описание |
| :------ | :------- |
| **Запланированное** | Флажок, указывающий, является ли завершение работы запланированным или незапланированным (например, из-за сбоя) |
| **Причина** | Раскрывающийся список для выбора причины завершения работы (варианты зависят от состояния флажка выше) |
| **Комментарий** | Текстовое поле для добавления пояснений; обязательно для заполнения при выборе варианта «Другое» |

---

**Настройка через реестр (альтернативный способ):**

1. Открыть редактор реестра (`regedit`).
2. Перейти к ключу: `HKLM\Software\Policies\Microsoft\Windows NT\Reliability`.
3. Создать (или изменить) параметры типа `DWORD` со следующими именами:
   - `ShutdownReasonOn` → значение `1`
   - `ShutdownReasonUI` → значение `1`

## 3. Контрольные вопросы

### Вопрос 1. Что такое групповые политики?

**Групповые политики (Group Policies)** — это набор правил, настроек и ограничений, применяемых к операционной системе для управления её поведением, интерфейсом и доступными функциями. Групповые политики позволяют администратору централизованно или локально:

- настраивать параметры рабочего стола и меню Пуск;
- запрещать или разрешать доступ к системным утилитам;
- управлять политиками безопасности и парольной политикой;
- ограничивать запуск определённых приложений.

По сути, это инструмент, который «диктует» Windows, как следует себя вести в тех или иных ситуациях.

---

### Вопрос 2. Категории объектов групповых политик

Объекты групповых политик (GPO, Group Policy Objects) делятся на две основные категории:

| Категория | Описание | Область действия |
| :-------- | :------- | :--------------- |
| **Локальные групповые политики** | Хранятся непосредственно на компьютере и применяются только к нему и его пользователям | Один компьютер |
| **Доменные групповые политики** | Хранятся на контроллере домена Active Directory и применяются централизованно ко всем компьютерам и пользователям в сети | Вся доменная сеть |

---

### Вопрос 3. Разделы групповых политик

В редакторе локальной групповой политики присутствуют два основных раздела:

| Раздел | Назначение |
| :----- | :--------- |
| **Конфигурация компьютера** | Параметры, действующие на уровне всей системы, независимо от того, какой пользователь вошёл. Применяются до авторизации пользователя. Примеры: сетевые настройки, политики безопасности, запуск служб, параметры аудита. |
| **Конфигурация пользователя** | Параметры, действующие только для конкретного пользователя. Применяются после входа в систему. Примеры: настройки меню Пуск, оформление рабочего стола, ограничения на запуск приложений, параметры интерфейса. |

---

### Вопрос 4. Как запустить редактор локальной групповой политики?

Чтобы открыть редактор локальной групповой политики, необходимо выполнить следующую последовательность действий:

1. Нажать комбинацию клавиш `Win + R` для вызова диалогового окна «Выполнить».
2. Ввести в текстовое поле команду `gpedit.msc`.
3. Нажать клавишу **Enter** или кликнуть по кнопке **OK**.

После этого откроется окно редактора, в котором можно просматривать, настраивать и отключать локальные групповые политики.

> **Важно:** Данная команда доступна только в версиях Windows Professional, Enterprise и Education. В домашних версиях (Home) редактор групповых политик отсутствует.

# Практическая работа
## Тема: Основные команды оболочки операционной системы GNU/Linux — работа с файлами и каталогами

**Цель занятия:** Ознакомление с базовыми командами командной строки GNU/Linux для навигации по файловой системе, управления файлами и каталогами, а также получения информации о дисковом пространстве.

---

## 1. Теоретические сведения

Операционная система GNU/Linux предоставляет мощный интерфейс командной строки (оболочку), позволяющий выполнять все операции по управлению файловой системой. В рамках данной работы изучаются следующие ключевые аспекты:

- навигация по файловой системе и просмотр содержимого каталогов;
- создание и удаление файлов и папок;
- копирование и перемещение объектов;
- использование шаблонов (масок) для групповых операций;
- поиск файлов и каталогов по различным критериям;
- создание символических ссылок;
- оценка занятого и свободного места на дисках.

---

## 2. Порядок выполнения работы

### 2.1. Подготовка рабочей среды

Для выполнения лабораторной работы используется компьютер с установленной операционной системой **Ubuntu** или **Debian** с графической оболочкой **GNOME**.

1. Включить компьютер и авторизоваться под полученными учётными данными.
2. Открыть эмулятор терминала одним из способов:
   - сочетание клавиш `Ctrl + Alt + T`;
   - через меню **Applications → Accessories → Terminal**.
3. Для оформления отчёта использовать текстовый процессор **LibreOffice Writer** (меню **Applications → Office → LibreOffice Writer**).

---

### 2.2. Навигация по файловой системе и просмотр списка файлов и каталогов

**Цель:** научиться определять текущее местоположение, перемещаться между каталогами и просматривать их содержимое.

| Действие | Команда | Назначение |
| :------- | :------ | :--------- |
| Показать текущий каталог | `pwd` | Выводит полный путь к текущей рабочей директории |
| Просмотр содержимого каталога | `ls` | Отображает список файлов и папок в текущем каталоге |
| Просмотр скрытых файлов | `ls -a` | Показывает все объекты, включая скрытые (начинающиеся с точки) |
| Детальный просмотр | `ls -l` | Выводит расширенную информацию: права доступа, владелец, размер, дата |
| Переход в каталог | `cd /bin` | Перемещает в указанную директорию |
| Переход в домашний каталог | `cd ~` | Возвращает в домашнюю папку пользователя |
| Возврат в предыдущий каталог | `cd -` | Переключает обратно в каталог, где пользователь находился до последнего перехода |

**Ход выполнения:**
1. Выполнить `pwd` и зафиксировать текущий путь.
2. Выполнить `ls` и записать результат.
3. Выполнить `ls -a` и записать вывод (обратить внимание на скрытые объекты).
4. Выполнить `ls -l` и записать результат.
5. Перейти в `/bin` командой `cd /bin`, выполнить `ls` и `ls -l`.
6. Перейти в `/sbin`, выполнить `ls -l`.
7. Вернуться в домашний каталог через `cd ~`.
8. Выполнить `cd -` и зафиксировать, в какой каталог произошёл возврат.

### 2.3. Создание и удаление файлов и каталогов

**Цель:** освоить команды создания и удаления объектов файловой системы.

Все действия в этом разделе выполняются внутри каталога `/tmp` (временная директория, содержимое которой удаляется при перезагрузке).

**Переход:**
```bash
cd /tmp

Создание и удаление каталогов:

| Действие | Команда | Примечание |
| Создать каталог | mkdir newdir1 | Создаёт папку с указанным именем |
| Проверить создание | ls -d /tmp/newdir1 | Проверяет наличие конкретного каталога |
| Удалить пустой каталог | rmdir newdir1 | Удаляет только пустую папку |
| Создать вложенные каталоги | mkdir -p newdir1/newdir2 | Ключ -p создаёт все промежуточные папки |
| Удалить вложенные каталоги | rmdir -p newdir1/newdir2 | Ключ -p удаляет всю цепочку пустых папок |

Ход выполнения:

Создать newdir1, проверить, удалить, проверить удаление.

Создать вложенную структуру newdir1/newdir2 через mkdir -p.

Проверить существование вложенного каталога.

Удалить структуру через rmdir -p.

Создание и удаление файлов:

| Действие | Команда | Примечание |
| Создать пустой файл | touch newfile1 | Если файл существует, обновляется время доступа |
| Создать файл через перенаправление | > newfile2 | Оператор > создаёт файл или перезаписывает существующий |
| Удалить файл | rm newfile2 | Безвозвратное удаление (не в Корзину) |

Ход выполнения:

Создать newfile1 командой touch, проверить через ls -l.

Создать newfile2 через > newfile2, проверить.

Удалить newfile2 через rm, проверить отсутствие файла.

Копирование и перемещение файлов:

| Действие | Команда | Примечание |
| Копирование файла | cp /etc/fstab /tmp | Копирует файл в указанную директорию |
| Копирование с сохранением атрибутов | cp -p /etc/passwd /tmp | Ключ -p сохраняет права, владельца и временные метки |
| Перемещение (переименование) файла | mv fstab fstab_new | Перемещает или переименовывает объект |

Ход выполнения:

Скопировать /etc/fstab в /tmp: cp /etc/fstab /tmp.

Сравнить время создания оригинала и копии через ls -l.

Скопировать /etc/passwd с ключом -p: cp -p /etc/passwd /tmp.

Проверить, что временные метки совпадают с оригиналом.

Переместить fstab в fstab_new: mv fstab fstab_new.

Проверить результат: оригинальное имя должно отсутствовать, новое — присутствовать.

Копирование и перемещение каталогов:

| Действие | Команда | Примечание |
| Создать вложенные каталоги | mkdir -p dir_a/dir_b | Создаёт структуру |
| Рекурсивное копирование каталога | cp -r dir_a dir_a_copy1 | Ключ -r — рекурсивно копирует всё содержимое |
| Копирование с сохранением атрибутов | cp -ra dir_a dir_a_copy2 | Ключи -r и -a (архивный) сохраняют все метаданные |
| Перемещение каталога | mv dir_a dir_a_new | Переименовывает или перемещает папку |

Ход выполнения:

Создать вложенные каталоги dir_a/dir_b.

Скопировать dir_a в dir_a_copy1 с ключом -r, сравнить временные метки (они должны отличаться).

Скопировать dir_a в dir_a_copy2 с ключом -ra, убедиться, что метки совпадают.

Переместить dir_a в dir_a_new через mv.

Проверить, что исходный каталог dir_a отсутствует, а dir_a_new существует.

Использование шаблонов при работе с файлами и каталогами:

| Шаблон | Значение |
| * | Любое количество любых символов |
| ? | Один любой символ |
| [abc] | Один из перечисленных символов |

Ход выполнения:

Перейти в /tmp: cd /tmp.

Создать несколько файлов: touch file1 file2 file3 file4.

Вывести список всех файлов, начинающихся с file: ls -l file*.

Удалить все файлы, начинающиеся с file: rm file*.

Проверить удаление: ls -l file* (результат — сообщение об отсутствии файлов).

Поиск файлов и каталогов:

| Действие | Команда | Примечание |
| Поиск файла по имени | find ~ -name '.bashrc' | Ищет в домашнем каталоге файл с точным именем |
| Поиск по расширению | find ~ -name '*.png' | Ищет все PNG-изображения |
| Поиск каталогов | find ~ -name 'Pictures' | Находит все папки с указанным именем |

Ход выполнения:

Найти файл .bashrc в домашней папке: find ~ -name '.bashrc'.

Найти все файлы с расширением .png в домашнем каталоге.

Найти все каталоги с именем Pictures.

Создание и использование ссылок на файлы и каталоги:

| Действие | Команда | Примечание |
| Создать символическую ссылку на файл | ln -s /etc/fstab fstab_link | Ключ -s создаёт символьную ссылку |
| Создать ссылку на каталог | ln -s /etc etc_link | Ссылка на каталог |
| Проверить ссылку после удаления оригинала | rm new_file → ls -l new_file_link | Ссылка становится «битой» (мёртвой) |

Ход выполнения:

Создать ссылку на /etc/fstab с именем fstab_link: ln -s /etc/fstab fstab_link.

Проверить через ls -l fstab_link (в выводе должна быть стрелка ->).

Создать ссылку на каталог /etc с именем etc_link: ln -s /etc etc_link.

Проверить через ls -ld etc_link.

Создать файл new_file и ссылку на него: ln -s new_file new_file_link.

Удалить оригинал: rm new_file.

Повторно выполнить ls -l new_file_link — обратить внимание на мигающий/выделенный цвет и сообщение об отсутствии целевого файла.

Оценка занятого и свободного пространства:

| Действие | Команда | Примечание |
| Оценка размера каталога | du -s -h /etc | Ключ -s — суммарно, -h — в человекочитаемом формате |
| Интерактивный анализ | ncdu /usr | Утилита для визуальной оценки размера (закрыть q) |
| Свободное место на дисках | df -h | Показывает общий, использованный и доступный объём |

Ход выполнения:

Определить размер каталога /etc: du -s -h /etc.

Запустить ncdu /usr, сделать скриншот, выйти по q.

Выполнить df -h, зафиксировать результаты.
